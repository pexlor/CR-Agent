# 实现决策

## 设计基线

- 需求基线采用《需求拆解.md》中的 C-001～C-023 及 FR-001～FR-009、FR-011～FR-028；FR-010 明确不纳入首版。
- 验收基线采用《验收清单.md》的 AC-01～AC-14，固定样例必须在运行前标注预期。
- Review Tool 采用声明式规则包 contract；工具不得通过仓库脚本、测试、构建或插件执行扩展。

## 固定版本

- schema version: `1`
- security rules version: `1`
- tool contract version: `1`
- report template version: `1`

## 不可变裁决

- 首版仅输出 Markdown，不向 GitHub PR 或 GitLab MR 发布评论。
- 仅支持 `github.com` 与 `gitlab.com` 的 HTTPS PR/MR URL，不支持自建实例。
- 每个平台使用一份预配置共享只读凭证；凭证不进入任务 DTO、日志、数据库或报告。
- 外部输入、工具结果、模型响应和错误均按不可信数据处理；安全扫描失败时 fail closed。
- 任务状态、预算、Trace、checkpoint 与报告快照必须可恢复、可核对，不能以“无发现”掩盖未完成。
- 领域层不依赖 CLI、数据库、SDK、网络、密钥环或模板引擎适配器。
