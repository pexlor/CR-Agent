# 已知限制

- 首版只支持 `github.com` 和 `gitlab.com` 的 HTTPS PR/MR URL，不支持企业自建平台。
- 平台输入固定启动时的 base/head SHA；源对象之后的更新不会自动混入当前任务。
- 首版只生成本地 Markdown 报告，不向 PR/MR 发布评论。
- 预算单位是 token，不支持人民币或其他金额预算。
- 不执行被审查仓库的构建、测试、脚本、插件、钩子或依赖。
- 固定样例用于验证约定行为，不代表发现所有未知缺陷或所有敏感信息。
- 模型输出、平台响应或安全扫描不确定时，结果会变为 `unknown` 或 `partial`。
- 当前 CLI 运行时的状态服务主要面向单进程本地使用，不承诺并发吞吐指标。
